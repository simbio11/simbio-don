## 처리 방식

- 배경 판정: `min(R,B) - G` 를 마젠타 정도로 계산. 시트 테두리에 닿은 연결요소만 배경으로 제거해
  볼터치·귀 안쪽의 분홍은 보존합니다.
- 가장자리: 배경까지 8px 전이 구간에만 소프트 알파를 적용하고, 색은 가장 가까운 불투명 픽셀에서
  끌어와 채웁니다(디스필 대신 색 전파) — 보라/녹색 테두리 없음.
- 크롭: 연결요소 소속으로 칸을 나눠 옆 칸 캐릭터·장식이 섞이지 않게 했고, 표정 8종은 몸통
  아래·가운데를 고정 앵커로 삼은 공통 캔버스에 배치해 표정 전환 시 위치가 흔들리지 않습니다.
- 검증: 결과물의 알파 있는 픽셀 중 강한 마젠타(키니스 > 70) 잔여는 88장 전부 0개입니다.

## 사용

- 앱에서는 `sprites/` 의 PNG(투명 배경, 224색 팔레트)를 그대로 쓰면 됩니다.
- 더 큰 해상도가 필요하면 `sheet.*` 원본에서 다시 자르면 됩니다(원본 배경은 `#FF00FF` 계열).
