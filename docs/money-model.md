# 돈 계산 방식 (0.31~)

오픈소스 가계부 [Sure](https://github.com/we-promise/sure)(Maybe Finance를 이어받은 앱)의 방식을 **본떠서**(코드는 가져오지 않음 — Sure는 AGPL) 단순하게 다시 짰다.
목표: 숫자가 꼬이지 않게, 모든 숫자가 한 가지 계산에서 나오게.

## 1. 기록은 다섯 가지뿐

| 종류 | 예 | 생활비(예산) | 통장 잔액 |
|---|---|---|---|
| 생활비 지출 `SPEND` | 밥, 커피, 쇼핑 | 빠짐 | 빠짐 |
| 환불 `REFUND` | 승인취소 | 돌아옴 | 들어옴 |
| 예외 지출 `EXCEPTION` | 병원비, 경조사 | 이번 달에서 빠짐 (그 주는 그대로, 다음 주부터 나뉨) | 빠짐 |
| 고정 지출 `FIXED` | 월세, 통신비 | **기록만** (월급에서 미리 뺀 돈) — 달력·통계·지출 합계에 안 들어감, 가계부 맨 아래 따로 | 빠짐 |
| 이체 `TRANSFER` | 카드값, ATM, 저축, 내 계좌끼리 | 안 들어감 | 옮겨짐 |
| 수입 `INCOME` | 월급, 부수입 | 안 들어감 | 들어옴 |

Sure의 거래 종류(standard / funds_movement / cc_payment / one_time …)처럼, **예산에 들어가는 건 생활비 지출과 환불·예외 지출뿐**이다.

## 2. 생활비 = 계획 + 조정, 남은 돈 = 생활비 − 쓴 돈

```
생활비(이번 달) = 월급 − 고정 지출 − 계획한 저축   (또는 직접 정한 생활비)
               + 조정 (BudgetChange)
남은 생활비     = 생활비 − 쓴 돈(생활비 지출 + 예외 지출 − 환불)
```

**조정**은 쓴 돈이 아니라 예산 자체가 바뀐 것이라 남은 날에 다시 나뉜다.
- 계획보다 **더 저축**으로 옮긴 돈 → 생활비에서 빠짐 (계획한 저축까지는 그대로)
- 저축에서 **꺼낸** 돈 → 생활비에 더함
- **직접 고침**(월급·생활비 화면), **남은 생활비를 통장에 맞추기** → ± 그대로

0.30까지는 "통장에 맞추기"가 오늘 날짜 환불·지출 기록을 남겨서 **이번 주 남은 돈만** 갑자기 커지거나 작아졌다. 이제는 예산 조정이다.

## 3. 주 예산은 이월 계산 없이

```
이번 주 쓸 수 있는 돈 = (이번 주 시작 때 남은 생활비 − 미리 떼어 둔 돈) × 이번 주 날 수 ÷ 남은 날 수
이번 주 남은 돈       = 이번 주 쓸 수 있는 돈 − 이번 주 쓴 돈
오늘 몫               = (이번 주 남은 돈 − 이번 주 계획) ÷ 이번 주 남은 날
```

- 아끼면 남은 주가 저절로 늘고, 더 쓰면 저절로 준다. 따로 "이월"을 계산하지 않는다.
- 마지막 주의 남은 돈 = 한 달 남은 생활비 (늘 맞는다).
- 아낀 비율·초과 판정(결산·잔디·보상)은 **기본 주 예산**(생활비를 날 수로 나눈 것) 기준 — 아끼고 몰아 쓰기로 보상만 쌓는 것은 막는다.

## 4. 통장 잔액은 계획 옆에 따로

Sure처럼 "계획(예산)"과 "실제 있는 돈(통장)"을 섞지 않고 나란히 보여 준다.
- 잔액 = 처음 잔액(또는 마지막 자산 점검) + **오늘까지** 적힌 기록. 할부 남은 달처럼 앞으로 적힐 기록은 그날이 와야 들어간다.
- 홈 "통장과 생활비 차이"는 통장 + 현금 − 생활비로 쓴 카드값(이번 달 안에 나갈 할부 몫 포함) + 받을 돈 − 보낼 돈 − 통장 없는 지출 과 남은 생활비를 견준다.

## 5. 이체 짝짓기 (Sure의 transfer matching)

- A 통장에서 나간 송금 + B 통장에 들어온 입금, 금액이 거의 같고(1,000원 또는 1% 안 — 수수료) 사흘 안 → "내 계좌끼리 옮긴 돈이에요?" 확인 후 이체로. 차이는 수수료 지출.
- 짝이 없는 5만 원 넘는 송금 → 어디로 갔는지(저축 통장 · 내 다른 통장 · 지출 맞아요) 묻는다.
- "아니에요"는 기억해서 다시 안 묻는다 (`moveState = 2`).
- 엔빵 정산도 같은 방식: 한 사람 몫과 1,000원 또는 10% 안이면 "정산이에요?"를 홈에서 바로 묻는다.

## 6. 부자들의 소비법

- **필요 vs 욕구**: 기록마다 "필요해서 / 갖고 싶어서". 고르지 않으면 분류로 (밥·교통·생활·의료·교육·주거·경조사·반려동물 = 필요).
- **최저시급 환산**: 사려는 것·욕구 소비가 최저시급(2026년 10,320원)으로 몇 시간 일한 돈인지, 한 달에 한 번 참으면 1년에 얼마인지.
- **7일 참기**: 사고 싶은 것을 담으면 7일 뒤 아침에 "아직도 사고 싶나요?" 알림. 안 사면 "참아서 아낀 돈"에 모인다.
