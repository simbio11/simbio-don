## 0.16 결정: 모은 돈 나누기 — 저축 · 목표 · 아낀 돈 (2026-10-25)

요청: "모은 돈에 예금하는 게 들어가는데 제대로 구분해야 돼. 작은 목표를 위해 모으는 돈을 따로 하고 저축하는 걸 따로".

| 항목 | 결정 |
| :--- | :--- |
| 세 칸 | 홈 "모은 돈"을 **저축**(예금·적금·투자처럼 오래 모으는 돈) · **목표**(여행·노트북처럼 쓰려고 모으는 돈) · **아낀 돈**(생활비에서 남긴 돈 중 아직 목표에 안 넣은 돈)으로 나눔. 모은 돈 모두 = 저축 + 목표 + 안 넣은 아낀 돈 |
| 저축 | 저축·예금·투자 통장 합 (목표에 이은 통장은 뺌). 그런 통장이 없으면 월급에서 먼저 뗀 저축의 합(어림)으로 보이고 "통장을 넣으면 실제 금액으로" 안내. 자산 탭·첫 설정의 "모으는 돈"은 목표와 헷갈리지 않게 **"저축·투자"**로 이름을 바꿈 |
| 목표는 넣은 만큼만 | 예전엔 모은 돈(예금 포함)으로 목표를 위에서부터 저절로 채웠음 → 이제 목표마다 **넣은 돈**으로만 참. 넣기: **아낀 돈에서**(안 넣은 만큼까지) / **따로 생긴 돈**(보너스·용돈·중고 판매). 빼기: 아낀 돈에서 넣었던 만큼은 아낀 돈으로 돌아감. 목표를 지우면 넣은 돈도 돌아감. "썼어요"면 모은 돈은 쓴 것으로 남음. 넣기·빼기는 팝업 대신 그 목표 아래에 펼침 |
| 통장 잇기 | 목표용 통장(세이프박스·모으기 통장 등)을 목표에 이으면 그 **통장 잔액이 곧 목표의 돈**, 그 통장은 저축 합계·자산 점검에서 빠짐 (순자산에는 그대로) |
| 아낀 돈 | 달마다 생활비에서 남긴 돈(넘게 쓴 달은 0으로, 지난달 아낀 돈을 깎지는 않음)의 합 − 아낀 돈에서 목표에 넣은 돈. 홈에 "아낀 돈 중 목표에 안 넣은 돈 n원 · 목표에 넣기" |
| 위젯 | 모은 돈 위젯: 큰 숫자는 모은 돈 모두, 아래 줄 "저축 · 목표 · 아낀 돈" |
| 옮기기 | 업데이트하면 예전 목표는 0원에서 다시 시작(예금으로 채워져 보이던 것) — 안 넣은 아낀 돈으로 바로 넣을 수 있음 |
| 저장 | DB v12: goal_move(목표에 넣고 뺀 돈·어디서), savings_goal.accountId. 백업 형식 7 |
