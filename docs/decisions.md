## 구체화 (2026-10-10)

| 항목 | 결정 |
| :--- | :--- |
| 목표 | 실제 돈이 빠져나가는 **기분**은 그대로, 현실 돈은 안 나감. **① 매달 쓰는 돈을 아끼고 정리 ② 소비 욕구 대리 해소** |
| 현실/게임 분리 | 현실은 **원**(예산·지출·아낀 돈·먼저 뗀 저축), 게임은 **마일**(창고·등급·마일리지·모의 쇼핑). 색·단위로 화면 구분. 마일리지는 원화로 표시하지 않음("약 OO원 상당" 금지). "모은 돈"은 실제 돈에만, 모의 구매 돌려받기는 "참은 금액". 모의 결제 화면은 진짜처럼 보이되 "모의 결제" 표시 상시 |
| 첫 화면 | 맨 위 **실제 이번 주 쓸 수 있는 돈** + 이번 달 아낀 돈. 아래 다른 색 게임 영역(배송 중·마일리지·모의 쇼핑) |
| 가격 | **실제 가격 그대로** (10배 등 부풀리기 안 함 — 게임머니처럼 느껴져 현실감이 사라짐) |
| 모의 지갑 | **이번 달 가용액**(월급 − 고정비 − 먼저 떼는 저축). 실제 지출·모의 구매 모두 여기서 빠지는 것처럼 보임 |
| 모의 구매 처리 | 주 예산은 깎지 않음. **주말에 돌려받기** → "참은 금액"으로 기록 (게임 기록, 모은 돈 아님), 산 물건은 창고에 남음 |
| 실제 지출 | 결제 알림으로 들어온 진짜 지출만 주 예산을 깎음 (예산 관리 담당) |
| 창고 연결 | 모의 구매는 주중 **배송 중**. 주말 결산에서 실제 예산을 지키면 전부 창고 도착, 초과하면 **초과액만큼 반품** (반품할 물건은 사용자가 고름) |
| 소득 공정성 | 등급·업적·연속 기록은 **금액이 아니라 비율**(주 예산 대비 지킨 %)로 매김. 창고 꾸미기·도감·세트 완성 등 금액과 무관한 놀거리 둠 |
| 비싼 물건 | 한 달 가용액보다 비싼 물건은 **마일리지**로 구매 (목표 물건 진행률 표시) |
| 마일리지 | **실제로 아꼈을 때만** 쌓임. 주 예산 대비 아낀 **비율**로 지급(예: 1%당 100마일) + **연속 달성 보너스**. 모의 구매 돌려받기는 마일리지 0 (일부러 쓰고 돌려받는 꼼수 차단) |
| 마일 환산 | 물건 원화 가격 → 마일은 **모두에게 같은 비율**(내부 100원 = 1마일). 마일리지가 비율로 쌓이므로 소득과 무관하게 같은 속도로 살 수 있음 |
| 재화 불리기 | **마일리지만** 불림. 실제 주 예산은 절대 늘지 않음. 목적: **복리의 맛보기** |
| 예치 ("마일 키우기") | 실제 이자와 헷갈리지 않게 게임 이름 사용. **고정 이율 + 자유 입출금**, 주 단위 복리. 상한 없음. 기본 이율 주 0.5% (1년 약 1.3배, 3년 약 2.2배) — 너무 높으면 마일리지 인플레로 물건이 공짜가 됨 |
| 미니게임 | 마일리지 보상, **주간 획득량의 5~10% 상한** 유지 |
| 카탈로그 | **공유하기로 가져오기** — 쿠팡·배민 등에서 "공유 → 이 앱"으로 받은 텍스트에서 상품명·가격 추출, 못 채우면 직접 입력. 스크래핑 없음 |
| 캐릭터와 집 (2026-10-10) | 가상의 내 캐릭터와 집. **집이 창고 역할** — 모의로 산 물건이 실제 모습처럼 집에 쌓여 **과소비했을 때의 가상 모습**을 보여줌 ("이 물건들 실제로 샀으면 총 OO원"). 아껴서 받은 **마일로 집 업그레이드**(원룸 → 투룸 → …)와 살림거리 구매. 실제 돈(원)은 건드리지 않음 |
| 캐릭터 | **도트 사람, 꾸미기 가능**(머리·얼굴·옷). WEB-5 도트 스타일 재사용. 모의로 산 옷·신발을 입힐 수 있음. 예산 상태에 따라 표정 변화 — 넘겨도 혼내지 않고 응원 |
| 그림 (2026-10-17 변경) | 이모지·임시 그림이 촌스러워서 **도트 그래픽 전면 구축** — 같은 팔레트로 생성하는 그림 생성기(`tools/pixelart`), 원룸 장면(배경·가구·물건·캐릭터 깜빡임), 카테고리·물건·탭 아이콘 전부 도트 (docs/art-spec.md) |
| UI (2026-10-17) | ~~화면 전체를 도트 UI로 (갈무리11 글꼴, 도트 패널)~~ → 같은 날 변경: 도트 UI가 과해서 **쇼핑앱식 세련된 UI**로. 밝은 회색 바탕 + 흰 둥근 카드, 시스템 글꼴, Material Symbols 아이콘, 카테고리는 색 동그라미 아이콘, 모의 쇼핑은 실제 쇼핑몰 주문/결제 화면처럼(배송지·주문 상품·결제 수단·결제 금액·하단 고정 결제 버튼). **도트는 게임 그림(방·캐릭터·물건)에만**. 현실 돈 = 파랑, 게임 = 보라 카드 구분은 그대로 |
| 방 그림 v2 (2026-10-17) | 음영 3~4단계로 다시 그림. 소품(스탠드·전구줄·벽시계·화분·하트 쿠션), 시간대(낮·노을·밤)에 따라 창밖 하늘·햇빛·밤 조명이 바뀌고, 캐릭터(22×28)가 러그 위를 걸어 다님. 응원 표정은 주먹 쥔 '화이팅' 자세 |
| 자동 반품 | 결산 때 반품할 물건을 안 고르고 정오가 지나면 **가장 나중에 산 것부터** 초과액이 채워질 때까지 반품 (M1 기본값) |
| 배치 | **자리가 정해진 칸** — 방마다 침대·책상·신발장·옷장 같은 칸. 가구는 칸을 눌러 골라 놓고, 모의로 산 물건은 카테고리에 맞는 칸에 자동으로 들어감. 넘치면 바닥에 쌓임. 자유 배치는 반응 보고 나중에 |
| 먹을거리 | 모의로 산 치킨·커피·배달은 캐릭터가 먹고 **빈 상자·컵·봉투 쓰레기**가 집에 쌓임. 주말 결산 때 **분리수거**로 치움. 먹은 기록은 도감에 남음 |
| 쌓였을 때 | 집 크기마다 **수납 칸**이 정해져 있고, 넘치면 바닥에 쌓여 어질러지고 캐릭터 동선이 막힘. 벌은 없고 정리는 선택: **수납 가구를 마일로 사기 · 집 넓히기(이사) · 비우기**(도감에는 남음) |
| 창고 그림 | **카테고리별 도트 아이콘** — 상품명으로 카테고리 추측(틀리면 사용자가 수정), 상품 사진은 안 씀. WEB-5 도트 스타일·이미지 생성 파이프라인 재사용. 카테고리별 도감 |
| 아이템 등급 | 주말 결산 때 **그 주 실제로 아낀 비율**로 결정 (안: 0~9% 일반 · 10~24% 레어 · 25%+ 전설). 랜덤 뽑기 없음 (사행성 배제) |
| 예외 지출 | 병원비·경조사비 등은 **예외 지출**로 표시 → 주 예산은 안 깎고 월 가용액에서만 빠짐, 남은 주 예산을 다시 나눔. **월 2회** 제한 |
| 알림 반영 | 확실한 건 **자동 반영**. 중복 의심(비슷한 시각·같은 금액), 고정비와 비슷한 건, 취소·환불은 **확인 필요함**에 모아 탭 한 번으로 정리. 주말 결산 전 확인함 비우기 |
| 결산 요일 | 초기 설정에서 **사용자가 고름** (기본 월요일, 그 전날이 주의 마지막 날). 그날 아침 결산쇼, 늦은 알림을 기다려 **정오까지 유예** 후 자동 결산. 변경은 **다음 달부터** 적용 |
| 한 달 기준 | **월급날 기준** — 월급날 ~ 다음 월급날 전날. 월급날이 주말·공휴일이면 앞당겨진 입금일 반영 (공휴일 목록은 앱에 내장) |
| 먼저 떼는 저축 | 초기 설정에서 **매달 먼저 떼어둘 저축액**을 정함. 주 예산 = 월급 − 고정비 − 저축. 모의 지갑(이번 달 가용액)도 저축을 뺀 금액. 실제 이체는 은행 앱 자동이체에 맡기고 앱은 금액만 앎 |
| 아낀 돈 | 주간 결산 후 남은 돈은 **다음 주로 이월** (쓸 수 있는 돈으로 표시) |
| 이월 기준 | 등급·마일리지·반품은 **기본 주 예산 기준**으로 잼. 이월분을 쓰면 그 주는 초과로 처리 (아끼고 몰아 쓰기로 보상만 쌓는 꼼수 차단) |
| 월급 입력 | **월급날마다 확인** — 지난달 금액 미리 채움, 은행 입금 알림을 잡으면 그 금액 제안, 탭 한 번으로 새 달 예산 생성. 상여금은 이번 달에 쓸지 따로 떼둘지 선택 |
| 첫 달 | 한 달 중간에 처음 시작하면 **오늘부터** 기록. 그 달 생활비는 남은 날 몫(1,000원 단위 내림)을 기본값으로 보여주고 사용자가 고침. 지난 날 지출은 모르므로 "아낀 돈"에 넣지 않음 (2026-10-10, 화면 테스트 중 발견) |
| 카테고리 | 11종(식비·카페·배달·교통·쇼핑·생활·의료·문화·경조사·교육·기타). 결제 알림은 본문에서 **가게 이름을 뽑아** 분류. 사용자가 고친 가게는 기억해 다음부터 그대로 (같은 가게 기존 기록도 같이 바꿀지 선택) |
| 차트 | 카테고리는 11개라 색 대신 **이모지·이름 + 한 색 막대**(도넛 안 씀 — 비슷한 값 비교가 어려움). 지출 속도는 실제 누적(파랑) vs 고르게 쓸 때(회색), 누르거나 끌면 날짜별 값. 초과는 상태색 + ⚠ 문구 |
| 달 이름 | 월급날 기준 한 달은 두 달에 걸쳐서 "9월" 대신 **기간(9/26 ~ 10/25)**으로 표시 |
| 짧은 주 | 한 달 시작·끝의 **3일 이하** 주는 옆 주에 합침 (최대 10일). 4~6일 주는 그대로, 마일리지는 일수에 비례 |
| 알림 규칙 | **앱 선택 → 키워드** 2단계, 사용자 설정 가능. 고르지 않은 앱의 알림은 본문을 열지 않음. 앱별 키워드 규칙(예: 결제·승인→지출, 취소·환불→환불, 광고·혜택→무시). 기본 프리셋: 삼성페이 · 토스(페이·뱅크) · 카카오페이·뱅크 · 카드사 앱. 문자 앱은 켤 때 스미싱 경고 |
