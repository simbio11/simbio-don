## 구체화 (2026-10-10)

| 항목 | 결정 |
| :--- | :--- |
| 목표 | 실제 돈이 빠져나가는 **기분**은 그대로, 현실 돈은 안 나감. 소비 욕구 해소 + 예산 관리 |
| 가격 | **실제 가격 그대로** (10배 등 부풀리기 안 함 — 게임머니처럼 느껴져 현실감이 사라짐) |
| 모의 지갑 | **이번 달 가용액**(월급 − 고정비). 실제 지출·모의 구매 모두 여기서 빠지는 것처럼 보임 |
| 모의 구매 처리 | 주 예산은 깎지 않음. **주말에 돌려받기** → "참은 돈"으로 기록, 산 물건은 창고에 남음 |
| 실제 지출 | 결제 알림으로 들어온 진짜 지출만 주 예산을 깎음 (예산 관리 담당) |
| 창고 연결 | 모의 구매는 주중 **배송 중**. 주말 결산에서 실제 예산을 지키면 전부 창고 도착, 초과하면 **초과액만큼 반품** (반품할 물건은 사용자가 고름) |
| 소득 공정성 | 등급·업적·연속 기록은 **금액이 아니라 비율**(주 예산 대비 지킨 %)로 매김. 창고 꾸미기·도감·세트 완성 등 금액과 무관한 놀거리 둠 |
| 비싼 물건 | 한 달 가용액보다 비싼 물건은 **마일리지**로 구매 (목표 물건 진행률 표시) |
| 마일리지 | **실제로 아꼈을 때만** 쌓임. 주 예산 대비 아낀 **비율**로 지급(예: 1%당 100마일) + **연속 달성 보너스**. 모의 구매 돌려받기는 마일리지 0 (일부러 쓰고 돌려받는 꼼수 차단) |
| 재화 불리기 | **마일리지만** 불림. 실제 주 예산은 절대 늘지 않음. 목적: **복리의 맛보기** |
| 예치 | **고정 이율 + 자유 입출금**, 주 단위 복리. 상한 없음. 기본 이율 주 0.5% (1년 약 1.3배, 3년 약 2.2배) — 너무 높으면 마일리지 인플레로 물건이 공짜가 됨 |
| 미니게임 | 마일리지 보상, **주간 획득량의 5~10% 상한** 유지 |
| 카탈로그 | **공유하기로 가져오기** — 쿠팡·배민 등에서 "공유 → 이 앱"으로 받은 텍스트에서 상품명·가격 추출, 못 채우면 직접 입력. 스크래핑 없음 |
| 창고 그림 | **카테고리별 도트 아이콘** — 상품명으로 카테고리 추측(틀리면 사용자가 수정), 상품 사진은 안 씀. WEB-5 도트 스타일·이미지 생성 파이프라인 재사용. 카테고리별 도감 |
| 아이템 등급 | 주말 결산 때 **그 주 실제로 아낀 비율**로 결정 (안: 0~9% 일반 · 10~24% 레어 · 25%+ 전설). 랜덤 뽑기 없음 (사행성 배제) |
| 예외 지출 | 병원비·경조사비 등은 **예외 지출**로 표시 → 주 예산은 안 깎고 월 가용액에서만 빠짐, 남은 주 예산을 다시 나눔. **월 2회** 제한 |
| 알림 반영 | 확실한 건 **자동 반영**. 중복 의심(비슷한 시각·같은 금액), 고정비와 비슷한 건, 취소·환불은 **확인 필요함**에 모아 탭 한 번으로 정리. 주말 결산 전 확인함 비우기 |
| 결산 요일 | 초기 설정에서 **사용자가 고름** (기본 월요일, 그 전날이 주의 마지막 날). 그날 아침 결산쇼, 늦은 알림을 기다려 **정오까지 유예** 후 자동 결산. 변경은 **다음 달부터** 적용 |
| 한 달 기준 | **월급날 기준** — 월급날 ~ 다음 월급날 전날. 월급날이 주말·공휴일이면 앞당겨진 입금일 반영 (공휴일 목록은 앱에 내장) |
| 짧은 주 | 한 달 시작·끝의 **3일 이하** 주는 옆 주에 합침 (최대 10일). 4~6일 주는 그대로, 마일리지는 일수에 비례 |
| 알림 규칙 | **앱 선택 → 키워드** 2단계, 사용자 설정 가능. 고르지 않은 앱의 알림은 본문을 열지 않음. 앱별 키워드 규칙(예: 결제·승인→지출, 취소·환불→환불, 광고·혜택→무시). 기본 프리셋: 삼성페이 · 토스(페이·뱅크) · 카카오페이·뱅크 · 카드사 앱. 문자 앱은 켤 때 스미싱 경고 |
