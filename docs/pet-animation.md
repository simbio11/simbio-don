# 반려동물 모션 기획 — WEB-6 돈 아끼는 게임

집 안에서 돌아다니는 반려동물을 "진짜 걷는 것처럼" 보이게 만드는 애니메이션 사양.
2026-11-03 아린 작성. 결정 필요 항목은 §9.

## 0. 결론 먼저

- **걷기 6프레임 / 초당 10프레임**이 최소·최적으로 자연스럽다. 4프레임은 발이 2번만 접지해서
  픽셀아트에서 다리가 붙어 보이고, 8프레임 이상은 제미나이가 프레임 간 일관성을 못 맞춘다.
- **필수 14프레임**: 서기 4 + 걷기 6 + 앉기 2 + 자기 2. 이 14장으로 "집에서 사는 느낌"이 성립한다.
- 이동은 **오른쪽 한 방향만** 그리고 앱에서 좌우 반전. 프레임 수를 절반으로 줄이는 핵심.
- 첫 시험은 **품종 1종(코기 권장)** 으로 14프레임만 뽑아 상태머신까지 붙여 확인한다.

## 2. 자연스러움 규칙 (숫자로 고정)

1. **접지 프레임에서 발을 멈춘다.** 접지한 발이 다음 프레임에서 미끄러지면 즉시 CG 티가 난다.
   같은 발이 2프레임 연속 땅에 붙어 있는 구간에는 발 좌표를 고정한다.
2. **이동속도 = 스트라이드 ÷ 사이클.** 공식 `v(px/s) = stride(px) × fps ÷ frames` 를 지킨다.
   걷기 기본값: 스프라이트 기준 stride 42px, 6프레임/10fps → 70 sprite px/s.
   화면 배율 0.57배(210px → 120px)면 화면 40px/s. 이 값을 속도 상수로 박고 애니를 맞춘다.
3. **몸통 bob 1~2px.** 접지 프레임에서 아래, 패싱 프레임에서 위. 좌우 흔들림은 금지(픽셀아트에서 어색).
4. **머리·꼬리 1프레임 지연.** 다리 프레임 i의 머리 위치는 i-1 값을 쓴다. 이 지연만으로도 무게감이 생긴다.
5. **다리는 2관절.** 어깨→무릎→발. 무릎 굽힘은 패싱 프레임에서만 1~2px.
6. **그림자는 접지 프레임에서 살짝 크게.** 타원 그림자를 앱에서 그리고, 접지 시 폭 +4%.
7. **보간 금지.** 8~10fps 고정, 60fps로 부드럽게 늘리지 않는다(픽셀아트가 뭉개진다).
8. **전환은 80ms 크로스페이드 1회.** idle↔walk는 다리 위상을 맞추지 않아도 되지만, walk→sit는
   접지 프레임에서만 전환한다.
9. **속도 변화는 fps만 바꾼다.** 걷기(10fps, 70px/s) → 달리기(14fps, 100px/s). 프레임 그림은 재사용.
10. **좌우 반전 시 그림자·광원도 같이 뒤집힌다.** 광원을 좌상단 한 방향으로 통일해 두면 반전해도 티가 적다.

## 4. 생성 규격 (제미나이)

> 실제로 붙여넣을 프롬프트 전문은 [pet-animation-prompts.md](pet-animation-prompts.md) 에 있다(11종 · 동작별).

### 4.1 시트 규격
- **한 장에 3×2 격자(6프레임)**, 4:3 비율(`gemini-3-pro-image-preview`, 2K = 1536×1152).
  칸당 512×576 → 스프라이트 210px에 충분.
- 4프레임 동작(idle·eat·groom)은 **2×2 격자**, 1:1.
- 배경 `#FF00FF` 마젠타, 그림자·라벨·글자·테두리 금지.
- **모든 칸에서 발바닥 기준선(y)이 같아야 한다.** 격자 안에서 캐릭터를 위아래로 띄우면 후처리에서 못 맞춘다.

### 4.2 공통 블록 (모든 동작 프롬프트 맨 앞에 붙임)

```
픽셀아트 스프라이트 시트. 3열 2행 격자, 각 칸은 같은 캐릭터의 연속 동작 프레임.
캐릭터: [품종], 옆모습, 오른쪽을 바라봄. 모든 칸에서 크기·카메라·발바닥 기준선이 완전히 동일.
털 색은 주황 갈색 계열만 사용(#E8A05C / #C97B3F / #8C4A26), 외곽선은 어두운 갈색 #3A2418.
눈·코·혀·볼의 분홍은 털 색과 섞지 않음(털만 나중에 색 교체).
배경은 순수 마젠타 #FF00FF 단색. 그림자·바닥선·글자·라벨·테두리·모션블러 없음.
도트 화풍 유지: 안티앨리어싱·블러·업스케일·리사이즈 금지, 1px 외곽선.
```

### 4.3 동작별 한 줄 (걷기 예시)

```
1번(좌상): 앞다리 왼쪽 앞으로 접지, 오른쪽 뒤로 뻗음, 몸통 살짝 아래
2번(중상): 무게 실림, 몸통 가장 아래, 꼬리 살짝 올라감
3번(우상): 패싱 — 다리가 몸 아래로 모임, 몸통 가장 위, 머리 1px 위
4번(좌하): 반대 접지 — 오른쪽 앞다리 앞, 왼쪽 뒤로
5번(중하): 무게 실림, 몸통 아래, 꼬리 반대로
6번(우하): 패싱 — 3번과 같은 자세지만 앞뒤 다리 역할 반대
```

- 앉기 2프레임: `1번=서서 엉덩이 내리는 중(뒷다리 굽힘)`, `2번=앉은 자세 유지, 앞다리 곧게`.
- 자기 2프레임: `1번=엎드려 머리 숙임, 눈 감음`, `2번=같은 자세에서 갈비뼈만 1px 부풀림(호흡)`.
- 먹기 4프레임: `1=고개 숙임`, `2=그릇에 닿음`, `3=혀 내밀어 씹기`, `4=고개 살짝 들고 씹기`.
- 장난 6프레임: `1=앞발 들기`, `2=휘젓기 왼쪽`, `3=휘젓기 오른쪽`, `4=엉덩이 들썩`, `5=뒤로 살짝`, `6=다시 1로`.

### 4.4 실패 대응
- 프레임 간 크기가 흔들리면: 공통 블록에 "모든 칸에서 캐릭터 키가 픽셀 단위로 동일"을 한 줄 더 넣고 재생성.
- 다리는 맞는데 얼굴이 바뀌면: 1번 프레임을 확정한 뒤 **이미지→이미지**(참조 이미지 첨부)로 나머지 칸을 채운다.
- 6칸 중 2칸이 못 쓰게 나오면: **4프레임 낙하산**으로 쓰고, 반전 프레임(좌우 미러)을 2장 더 붙여 6프레임처럼 재생한다.
  (미러 프레임은 접지 위상이 정확히 반대라 오히려 자연스럽다.)

## 5. 파일 규격

```
assets/pets/<품종>/
  anim/
    idle_1.png … idle_4.png      # 210px 기준, 투명 배경
    walk_1.png … walk_6.png
    sit_1.png, sit_2.png
    sleep_1.png, sleep_2.png
  anim.json
```

`anim.json` (앱이 읽는 값 — 이게 단일 창구):

```json
{
  "frameHeight": 210,
  "anchor": { "x": 0.5, "y": 0.94 },
  "anims": {
    "idle":  { "frames": 4, "fps": 6,  "loop": true },
    "walk":  { "frames": 6, "fps": 10, "loop": true, "speedPxPerSec": 40 },
    "sit":   { "frames": 2, "fps": 5,  "loop": false },
    "sleep": { "frames": 2, "fps": 3,  "loop": true }
  }
}
```

- 파일명 규칙은 표정 스프라이트(`sprites/01_joy.png`)와 분리해 `anim/<상태>_<번호>.png`.
- 캔버스는 동작별로 달라도 되지만 **같은 동작 안에서는 반드시 동일**해야 한다(흔들림 방지).
  앵커는 `anchor` 값으로 맞추고, 크롭 기준은 bbox가 아니라 **발바닥 기준선**.

## 6. 털색 교체 규격

- 스프라이트는 **224색 팔레트 PNG**. 털은 4단 램프(밝음·기본·어두움·외곽선)로만 칠한다.
- 색 교체는 앱에서 **팔레트 스왑**(털 램프 4칸만 치환). 이미지 전체 hue 회전은 눈·코·혀까지 물들어 실패한다.
- 그래서 생성 시 "주황 갈색 계열만, 눈·코·혀 분홍은 별도" 조건이 프롬프트에 반드시 들어간다.
- 품종별 기본 팔레트: 코기 `#E8A05C` 계열, 시바 `#D9A16A`, 포메 `#E9C79A`, 불독 `#C9BEB0`, 푸들 `#E7C9A9`.

## 7. 앱 구현 노트 (Android)

- 상태머신: `IDLE → WALK → IDLE` (배회) / `SIT` / `SLEEP` / `EAT` / `PLAY`.
- 배회 루프: 3~8초 대기 → 방 안 임의 좌표 선택 → 경로 이동 → 도착 후 idle. 밤(22:30~08:00)엔 자주 `SLEEP`.
- 애니메이션은 `AnimationDrawable` 또는 프레임 인덱스 직접 갱신(권장: 후자, fps 제어 쉬움).
- 이동은 `walk` 재생 중에만 좌표를 갱신하고, 정지 시 즉시 idle로 80ms 크로스페이드.
- 방 안 y좌표에 따라 스프라이트 배율 0.9~1.1배(y-sort) — 원근감이 생기고 "살아있는" 느낌이 커진다.
- 반전: `scaleX = -1`로 처리. 그림자는 스프라이트에 굽지 말고 별도 타원으로 그린다(반전·확대 시 자연스러움).

## 8. 검수 체크리스트

- [ ] 마젠타 잔여 0 (`alpha>12 & keyness>70` 카운트)
- [ ] 프레임별 발바닥 기준선 편차 ≤ 1px
- [ ] 프레임별 캐릭터 높이 편차 ≤ 2px
- [ ] 접지 프레임에서 발 미끄러짐 없음(연속 프레임 발 좌표 고정 확인)
- [ ] 6프레임 루프 재생 시 튐 없음(1번↔6번 경계)
- [ ] 좌우 반전 시 광원·그림자 어색함 없음
- [ ] 앱에서 40px/s 이동 시 발이 미끄러지지 않음(§2-2 공식 검증)

## 9. 결정 필요

1. 첫 시험 품종: **코기** 제안(다리 짧고 색 대비 좋아 미끄러짐이 잘 보임). 다른 품종 원하시면 알려 주세요.
2. `eat`·`play`를 M0에 넣을지, 아니면 14프레임 검증 후로 미룰지.
3. Zzz·하트 같은 이펙트는 앱에서 그릴지, 스프라이트에 구울지(권장: 앱에서 그림).

## 10. 실측 기록 — 코기 1종 시험 (2026-11-03)

12프레임 생성 완료: `idle` 4 · `walk` 4 · `sit` 2 · `sleep` 2 → `assets/pets/corgi/anim/`.
`preview/*.gif` 로 재생 확인, `anim.json` 에 fps·캔버스·파일 목록 기록.

| 시도 | 결과 |
|---|---|
| 3열 2행 요청 | 모델이 3×3(9칸)로 그림 → 실패 |
| 2열 4행 요청(텍스트만) | 칸 수는 맞지만 다리 자세 변화가 거의 없음(서 있는 자세 8장) |
| **2열 4행 + 참조 이미지(image→image)** | 다리 자세가 확실히 달라짐 → **채택** |
| 2칸 요청(sit/sleep) | 2칸 정확히, 자세 전환 자연스러움 |

배운 것:
- **참조 이미지가 핵심.** 이미 확정된 옆모습 스프라이트를 마젠타 배경으로 합성해 첨부하고
  "이 캐릭터 그대로, 다리만 바꿔"라고 하면 몸통·얼굴이 고정된 채 다리만 달라진다.
- 모델은 6칸·4칸 같은 격자 수를 자주 어긴다. **2열 × 4행(8칸)이 가장 안정적**이다.
  (표정 시트도 같은 이유로 2×4가 잘 나왔다.)
- 8프레임을 요청해도 **좌우 다리를 구분한 진짜 8단계 걷기는 나오지 않는다.** 대신 위상이 다른
  4장을 골라 `넓은 보폭 → 무게 → 모음 → 모음 반대` 순으로 조립하면 8fps에서 걷기로 읽힌다.
  프레임 선택은 알파 마스크 픽셀 차이 행렬로 고른다(차이가 최대인 프레임 조합).
- 프레임마다 몸 크기가 조금씩 다르다 → **발바닥 기준선 + 중앙값 배율 정규화**로 흡수한다.
- 키잉 규칙 추가: **밝은 마젠타(m ≥ 90)는 연결요소와 무관하게 배경**으로 지운다. 칸 사이에
  갇힌 마젠타가 두 캐릭터를 한 덩어리로 이어붙여 프레임이 합쳐지는 사고를 막는다.
- 남은 한계: 진짜 4족 교대 보행은 이 방식으로 안 나온다. 필요하면 ① 프레임 수작업 보정
  ② 영상 모델(Wan)로 한 장을 움직여 프레임 추출 — 둘 다 후속 실험 대상.

## 11. 앱 연결 현황 (0.26, 2026-11-03)

`tools/pixelart/import_pets.py` 가 `anim/` 프레임을 `res/drawable-nodpi/pet_<품종>_m_<동작>_<n>.png` 로 가져오고
`PetArt.motions` 를 만든다. 가져올 때: 마젠타 테두리 정리, 좌우가 뒤집힌 칸 바로잡기(몸통·꼬리 쪽 기준),
같은 동작 안 상대 크기 유지 + 가장 큰 칸을 앉은 키(210px)에, 자는 그림은 0.68배, 발바닥 맞춤.

| 상태 | 처리 |
|---|---|
| 코기 `idle`·`play` | 그림체가 다르거나(서 있는 흰 코기) 깨져서 뺌 → 표정 그림으로 대신 |
| 치즈태비 `play` | 1칸뿐이라 뺌 |
| 비글 `sleep` | 앉은 그림이라 뺌 → 표정 `sleep` 으로 대신 |
| 장모 고양이 두 종 `sit`·`sleep`·`eat` | 서로 바뀌어 들어가 있어 맞바꿔 씀 |
| `eat` | 시바 믹스·치즈태비·장모 고양이·스피츠만 있음 |

**더 만들면 좋아지는 것** (같은 규격으로 넣고 스크립트만 다시 돌리면 앱에 붙는다)
1. 코기 `idle` 4칸·`play` 2~4칸 — 지금 걷기·앉기와 같은 그림체로.
2. 비글 `sleep` 2칸 (엎드려 자는 자세).
3. 치즈태비 `play` 2칸 이상.
4. 나머지 7종 `eat` 2칸 (고개 숙임 / 씹기).
5. 걷기는 지금 정면 3/4 제자리걸음이라 천천히(초당 11 방 픽셀) 움직인다. 옆모습 걷기 4~6칸이 생기면 더 자연스럽다.
