## 2. 사이즈 계산 (칸 해상도 → 최종 스프라이트)

| 항목 | 값 | 판단 |
|---|---|---|
| 요청 해상도 | 2K — 9:16 = 1536×2752, 1:1 = 2048×2048 | 4K는 과함(칸당 2배·생성 느림) |
| 칸 크기 | 9:16 → 768×688 / 1:1 → 512×512 | 실측 캐릭터 몸통 높이 450~470px |
| 최종 스프라이트 | 몸통 210px, 캔버스 약 350×256 | 2.2배 축소 여유 → 도트 안 뭉개짐 |
| 파일 크기 | 224색 PNG 1장 10~15KB | 16프레임 ≈ 200KB/품종, 11종 ≈ 2.2MB |

비율은 모델이 정하게 두세요. 9:16이 가장 여유 있지만 **1:1로 나와도 칸 512×512면 충분**하다.
비율 때문에 재생성하지 말 것.

## 4. 묶음 A — 걷기 8칸 (기준컷 첨부)

```

```

## 11. 실패 대응

| 증상 | 처방 |
|---|---|
| 칸 수를 어김(3×3, 5줄 등) | "정확히 2칸 × 4줄, 총 8칸"을 첫 줄로. 두 번 실패하면 그 묶음을 2×2(4칸)로 쪼갠다 |
| 두 동작이 섞임 | "1~4번은 서기, 5~8번은 장난"처럼 **칸 묘사보다 먼저** 한 줄로 선언 |
| 다리가 거의 안 움직임 | 기준컷 첨부 확인 + "몸통·얼굴 고정, 다리만" 한 줄 추가 |
| 칸 사이 검은 구분선 | "구분선·테두리 금지"를 맨 앞으로 |
| 발이 잘림 | "발밑 40px 여백" 유지, 칸 수 줄이기 |
| 프레임마다 몸 크기 차이 | "모든 칸에서 캐릭터 키가 픽셀 단위로 동일" 추가 |
| 다른 품종·다른 무늬 | 기준컷 재첨부 + "같은 동물·같은 무늬" 강조 |
