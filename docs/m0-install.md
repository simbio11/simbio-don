# M0 설치와 실사용 체크리스트

M0는 **예산 + 결제 알림 자동 기록**만 들어간 버전이에요. 게임 요소(모의 쇼핑·창고·마일리지)는 아직 없어요.
갤럭시에서 1~2주 써보면서 **결제 알림이 빠짐없이, 두 번 세지 않고 잡히는지** 확인하는 게 목적이에요.

## 1. 설치

1. 폰 브라우저로 GitHub 리포 → **Releases** → `debug-latest` → `simbio-don-debug.apk`를 눌러 받아요.
   (Releases에 없으면 **Actions** → 가장 최근 성공한 실행 → Artifacts의 `simbio-don-debug`를 받아 압축을 풀어요.)
2. 처음 한 번은 "출처를 알 수 없는 앱 설치"를 브라우저(또는 내 파일)에 허용해요.
3. 새 버전도 같은 방법으로 받아 설치하면 덮어써지고 기록은 그대로 남아요.

## 2. 처음 설정

- 월급(실수령액), 월급날, 고정비, 먼저 떼어둘 저축, 결산 요일을 넣어요.
- 월급날이 아닌 날 시작하면, 다음 월급날 전날까지 쓸 생활비를 한 번 정해요. 지난 날 지출은 모르니까 오늘부터만 기록해요.

## 3. 알림 자동 기록 켜기 (중요)

1. 첫 화면 **켜러 가기** → "결제 알림 자동 기록" 알림 접근 허용.
2. **설정 → 배터리 설정 열기** → 이 앱을 **제한 없음**으로. 갤럭시는 이걸 안 하면 며칠 뒤 알림 수신이 끊겨요.
3. 카드사·은행·간편결제 앱에서 **결제 알림을 켜두세요.** (구 D-8 가계부가 멈춘 이유가 이거였어요.)
4. **설정 → 알림 읽을 앱**에서 쓰는 앱이 켜져 있는지 확인해요. 목록에 없으면, 결제를 한 번 한 뒤 "최근 알림을 보낸 앱"에서 눌러 추가해요.

## 4. 1~2주 동안 볼 것

| 확인할 것 | 어디서 | 이상하면 |
| :--- | :--- | :--- |
| 결제할 때마다 기록되나 | 이번 달 내역 ("알림 자동") | 그 앱이 "알림 읽을 앱"에 켜져 있는지, 배터리 제한 없음인지 |
| 금액이 맞나 | 이번 달 내역 | 그 알림 문구를 알려주세요 (금액 추출 규칙 수정) |
| 한 번 결제가 두 번 잡히나 | 확인함 "중복일 수 있어요" | 3분 안에 다른 앱에서 같은 금액이면 확인함으로 가요. 그래도 두 번 잡히면 알려주세요 |
| 광고·인증번호가 지출로 잡히나 | 이번 달 내역 | 앱의 키워드 규칙 "무시"에 단어 추가 |
| 월세·보험 자동이체가 또 빠지나 | 확인함 "고정비와 비슷해요" | 고정비 이름·금액을 정확히 적어두기 |
| 결산이 뜨나 | 결산 요일 아침 첫 화면 배너 | 확인함이 남아 있으면 정오까지 기다려요 |

알림 문구가 잘못 읽히면, **그 알림 내용(개인정보는 가리고)** 을 알려주세요. 앱별 규칙을 맞춰 고칠게요.

## 모의 쇼핑 (0.3.0부터)

- 쿠팡·무신사 등에서 상품 화면의 **공유 → 돈't**을 누르면 상품명·가격이 채워진 모의 결제 화면이 열려요. 가격이 공유 글에 없으면 직접 넣어요.
- 앱의 **내 집 → 모의 쇼핑하기**로 직접 넣어도 돼요.
- 결제해도 실제 돈은 안 나가요. 주말 결산 때 돌려받고, 실제 예산을 지키면 집으로 배송, 넘기면 넘긴 만큼 반품돼요.

## 개인정보

- 모든 데이터는 폰 안에만 저장돼요. 인터넷 권한도 없어요.
- 고르지 않은 앱의 알림은 본문을 열지 않고, 앱 이름만 기록해요 (설정의 "최근 알림을 보낸 앱" 목록용).
- 확인함에 들어간 알림만 판단을 돕기 위해 문구를 저장하고, 정리하면 지워져요.
